\# Exercícios de TinyML



Repositório com exercícios e experimentos realizados durante meus estudos de TinyML, TensorFlow e TensorFlow Lite.



O objetivo é praticar conceitos de Machine Learning voltados para dispositivos com recursos limitados, passando desde o treinamento de modelos até a conversão para formatos mais adequados para sistemas embarcados.



\## Tecnologias utilizadas



\- Python

\- TensorFlow

\- TensorFlow Lite

\- TensorFlow Hub

\- TensorFlow Datasets

\- NumPy

\- Matplotlib

\- Jupyter Notebook



\## Conteúdo do repositório



Os notebooks incluem estudos e exercícios sobre:



\- Classificação de imagens

\- Transfer Learning

\- MobileNetV2

\- Preparação de datasets

\- Treinamento e validação de modelos

\- Avaliação de predições

\- Exportação de modelos

\- Conversão para TensorFlow Lite

\- Keyword Spotting

\- Aplicações de Machine Learning em dispositivos embarcados



\## Classificação de imagens



Um dos exercícios utiliza o dataset Rock Paper Scissors para classificar imagens em três classes:



\- Pedra

\- Papel

\- Tesoura
